E6 - Parcours de professionnalisation

BTS SIO - Option SLAM

L'épreuve E6 évalue le parcours de professionnalisation de l'étudiant à travers ses réalisations en milieu professionnel et scolaire. Elle valide les compétences en développement d'applications (SLAM : Solutions Logicielles et Applications Métiers), la capacité à concevoir, coder, tester et documenter des projets informatiques.

Ce dossier présente les situations professionnelles significatives réalisées à l'école IRIS et en entreprise, couvrant la modélisation de bases de données, le développement web applicatif et la programmation d'un client lourd.

Projet 1 : Application web ITMS SupportDesk

Conception et développement d'une application web légère de gestion des incidents et ticketing (ITMS) inspirée de GLPI. Déploiement d'une architecture PHP/MySQL avec séparation des fonctions métier, gestion des utilisateurs, typage strict et sécurisation contre les injections SQL via requêtes préparées (PDO).

Compétences clés validées
  • + Concevoir et développer une solution applicative web (PHP, HTML5, CSS3)
  • + Modéliser et administrer la base relationnelle (MySQL, tables utilisateurs & incidents)
  • + Sécuriser les flux et interactions avec la BDD (PDO, requêtes préparées, liste blanche)
PHP MySQL PDO / Sécurité SQL ITMS / Ticketing Apache

Projet 2 : Client lourd ITMS SupportDesk

Développement d'une application bureau (client lourd) interconnectée à la base de données centrale de l'ITMS SupportDesk. Conçue pour les techniciens de support, elle permet la supervision en direct des incidents, l'attribution, le traitement et la clôture assistée des tickets.

Compétences clés visées
  • + Concevoir et développer une interface graphique applicative (Client lourd / POO)
  • + Interconnecter l'application bureau à la base de données relationnelle MySQL
  • + Gérer le cycle de vie, les statuts et l'attribution des tickets pour les techniciens
